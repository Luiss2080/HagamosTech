# Layout - Estructura Base del Sitio

Componentes que definen la estructura general de todas las páginas.

## Componentes

| Archivo | Descripción |
|---------|-------------|
| `AppLayout.jsx` | Contenedor principal de la aplicación (envoltura de rutas) |
| `Header.jsx` | Barra de navegación superior con menú y logo |
| `Footer.jsx` | Pie de página con enlaces, contacto y redes sociales |
