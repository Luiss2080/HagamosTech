# Código Fuente - LOS CASTORES

## Estructura Principal

| Carpeta | Descripción |
|---------|-------------|
| `app/` | Núcleo de la aplicación (entrada, rutas, configuración global) |
| `pages/` | Vistas y páginas del sitio organizadas por módulo |
| `components/` | Componentes reutilizables (Layout, Interfaz, Modales, Widgets) |
| `store/` | Estado global con Zustand (autenticación, carrito, catálogo, modales) |
| `servicios/` | Servicios de comunicación con el backend (API, contacto) |
| `chat/` | Asistente virtual Niko con procesamiento de lenguaje natural |
| `styles/` | Hojas de estilo globales (Tailwind, modo oscuro) |
| `utils/` | Utilidades y helpers |
| `assets/` | Recursos estáticos (imágenes, fuentes, iconos) |
